# AFTER WAVE

> Хоррор-шутер на выживание от 63zyMHblN Project

Волны зомби не заканчиваются. Фургон — твоя единственная опора.
Пять стволов, шприц и два ремнабора. Продержись как можно дольше.

🎮 **[Играть / скачать с официального сайта](https://63zymhbln.github.io/After_wave_site/)**

## Об игре

AFTER WAVE — хоррор-шутер на выживание с волнами врагов.
Сложность: **КОШМАР**. Цель проста: выжить как можно дольше.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Ходьба |
| SHIFT | Бег |
| F | Взаимодействие с фургоном |
| E | Поднять патроны |
| F10 | Телепорт потеряшек |
| 1–5 | Оружие |
| ЛКМ | Огонь |
| ПКМ | Прицел (только снайперская винтовка) |

## Установка

1. Скачай архив `afterwave_1.0.zip` с [сайта](https://63zymhbln.github.io/After_wave_site/).
2. Распакуй в любую папку.
3. Запусти игру.
